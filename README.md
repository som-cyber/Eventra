# ÉVENTRA — Where Moments Become Memories

ÉVENTRA is a responsive event-discovery and registration website built with HTML5, CSS3, and vanilla JavaScript. It has no frontend framework, package installation, or build step.

## Run locally

Open `index.html` directly, use the VS Code Live Server extension, or start a static server from this folder:

```powershell
py -m http.server 8000
```

Then visit `http://localhost:8000`.

## Pages

- `index.html` — homepage, featured events, categories, about, and newsletter
- `events.html` — event search, category/date filtering, and date sorting
- `event-details.html?id=1` — event details and countdown
- `register.html?eventId=1` — event registration and confirmation
- `my-registrations.html` — view and cancel saved registrations
- `support.html` — help center, sample contact details, and sample policies

## Features

- Responsive navigation and smooth section scrolling
- Event search, category and date filters, and date sorting
- Event detail pages and upcoming-event countdowns
- Validated registration with duplicate checks and Local Storage persistence
- Prototype-only checkout with simulated success/decline outcomes; it never processes payments or requests payment credentials
- Multi-interest event discovery and a five-question experience personality quiz
- Preference-based event recommendations and transparent compatibility scores
- Monthly event calendar with date selection and grid/calendar views
- QR-coded digital registration passes with print and download options
- Saved favorites, persistent dark/light theme, and newsletter interactions
- Responsive premium design with scroll and hover animations

Interests, quiz results, event preferences, registrations (including demo payment status and reference), favorites, theme preference, and newsletter subscriptions are stored in the browser's Local Storage. Checkout is a local simulation only; no real payment is processed and no card, bank, or UPI credentials are collected. Digital passes are demonstration references; their QR codes are not verified entry credentials.
