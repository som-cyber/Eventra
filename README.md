## ✦ The Experience

ÉVENTRA is a modern event discovery and registration platform that makes finding your next experience feel personal.

From intelligent event recommendations to interactive personality quizzes and QR-powered digital passes, ÉVENTRA brings the entire event discovery journey together in one elegant experience.

**Discover differently. Experience more.**

---

## ✦ Features

| Feature | Experience |
|---|---|
| **Event Discovery** | Explore, search, filter, and sort events. |
| **Find Your Vibe** | Discover events based on your interests. |
| **Personality Quiz** | Find your event personality through a five-question quiz. |
| **Compatibility Score** | See how well an event matches your preferences. |
| **Interactive Calendar** | Explore events through a monthly calendar. |
| **Smart Registration** | Register with form validation and duplicate checks. |
| **Digital Event Pass** | Generate QR-coded registration passes. |
| **My Registrations** | View, manage, and cancel registrations. |
| **Favorites** | Save events you love. |
| **Theme Switching** | Switch between dark and light themes. |

## ✦ Get Started

Run ÉVENTRA locally in a few simple steps.

**1. Clone the repository**

```bash
git clone https://github.com/som-cyber/Eventra.git
```

**2. Enter the project directory**

```bash
cd Eventra
```

**3. Launch the website**

Use VS Code Live Server or run:

```bash
py -m http.server 8000
```

**4. Open in your browser**

```text
http://localhost:8000
```

That's it. No package installation or build command required.

## ✦ Under the Hood

ÉVENTRA uses browser-based Local Storage to preserve:

- Event registrations and demo checkout references
- User interests and quiz preferences
- Favorite events
- Theme preferences
- Newsletter subscription information

Your saved information remains available in the same browser unless its local storage data is cleared.

---

## ✦ Important Notes

ÉVENTRA is a frontend demonstration project.

- Registrations are stored locally in the browser.
- Checkout outcomes are simulated; no real payments are processed.
- QR-coded passes are demonstration references, not verified entry credentials.
- There is no production backend, centralized database, or server-side authentication.
